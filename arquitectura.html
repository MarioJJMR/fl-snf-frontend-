📋 Resumen del Sistema

Plataforma web interna para que las obras jesuitas de Fundación Loyola completen el Sondeo de Necesidades y Financiamiento (SNF) 2025. El sistema centraliza el llenado de formularios, gestión documental, y permite al equipo administrador monitorear el avance y generar reportes.

🔌 API REST

Base URL producción: https://fl-snf-backend-production.up.railway.app/api  ·  Todos los endpoints protegidos requieren header Authorization: Bearer <token>

MétodoEndpointAuthDescripción
AUTH
POST /auth/login Público Login con usuario y contraseña → JWT
POST /auth/google Público Login con Google id_token → JWT (email debe existir en BD)
POST /auth/logout JWT Revoca el token (jti → blacklist)
GET /auth/me JWT Devuelve los datos del usuario autenticado
OBRAS
GET/obrasJWTListar todas las obras activas
GET/obras/:idJWTDetalle de una obra
POST/obrasAdminCrear nueva obra
PUT/obras/:idAdminActualizar obra
DEL/obras/:idAdminEliminar obra (soft delete)
USUARIOS
GET/usuariosAdminListar usuarios activos (incluye email)
POST/usuariosAdminCrear usuario (acepta email para Google OAuth)
PUT/usuarios/:idAdminActualizar usuario (nombre, rol, email, obra_id)
DEL/usuarios/:idAdminDesactivar usuario (soft delete)
FORMULARIOS
GET/formularios/:obraIdJWTTodos los formularios de una obra
GET/formularios/:obraId/:formKeyJWTFormulario específico por clave
POST/formularios/:obraId/:formKeyJWTGuardar / actualizar formulario (upsert)
PROYECTOS
GET/proyectos/:obraIdJWTTodos los proyectos de una obra
GET/proyectos/:obraId/:tipoJWTProyectos por tipo (vigente | financiar)
POST/proyectos/:obraId/:tipoJWTCrear proyecto
PUT/proyectos/:idJWTActualizar proyecto (JSON_MERGE_PATCH)
DEL/proyectos/:idJWTEliminar proyecto
DOCUMENTOS
GET/documentos/:obraIdJWTListar documentos de una obra
POST/documentos/:obraIdJWTSubir archivos (multipart/form-data, campo archivos)
GET/documentos/:obraId/descargar/:idJWTDescargar archivo (solo documentos de la propia obra)
DEL/documentos/:idJWTEliminar documento y archivo de disco
SISTEMA
GET/healthPúblicoEstado del servidor: uptime, ambiente y conexión a BD
